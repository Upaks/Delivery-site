# Delivery Site 🚚

A static marketing site for an on-demand delivery service. Built with semantic HTML and modern CSS, it highlights delivery scenarios, customer testimonials, and call-to-action sections to help visitors book or learn more about the service.

## Features
- **Landing page layout** with hero, features, testimonials, and CTA blocks.
- **SVG + JPG assets** (icons, illustrations, and hero imagery) for a polished look.
- **Responsive design** so it works across desktop and mobile.
- **Ready for GitHub Pages** (already deployed in the repo history).

## Project Structure
- `index.html` – main landing page markup.
- `solution.html` (if present) – additional info or pricing page.
- `css/` – all stylesheet files for layout, colors, typography, and animations.
- `images/` – raster assets (JPG/PNG) used across the site.
- stand-alone `.svg` files – icons for logistics, apps, and illustrations.
- `.gitignore` – ignore rules for node_modules or tooling if you add any.

## Getting Started
```bash
git clone https://github.com/<your-user>/Delivery-site.git
cd Delivery-site
```
Open `index.html` directly in a browser or use a lightweight server:
```bash
npx serve .
```

## Customization Ideas
- Replace the copy/images with branding for your own courier startup.
- Hook the CTA button to a real signup form or booking portal.
- Add a contact form, pricing calculator, or logistics tracking section.
- Convert to a framework (React, Next.js) if you need dynamic data later.
